AMAHDROP WEBSITE
================

Files:
- index.html  : website structure/content
- styles.css  : responsive design
- script.js   : menu, tracking demo and WhatsApp contact form

HOW TO USE
1. Open index.html in a browser to preview the website.
2. Upload all three files to your web host.
3. Replace the temporary tracking demo with your real tracking/database system when ready.
4. Replace the emoji brand mark with your official AmahDrop logo when you have the logo file.
